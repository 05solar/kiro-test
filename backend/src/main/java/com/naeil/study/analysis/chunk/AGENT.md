# analysis/chunk — 에이전트 작업 규칙

## 지킬 것

- 크기와 겹침은 설정값으로 받는다. 코드에 숫자를 박지 않는다.
- 문단 경계를 우선한다. 문장을 중간에서 자르지 않는다.
- 조각마다 문서 ID, 파일명, 순번을 유지한다.
- 잘못된 설정값은 생성자에서 막는다.
- 진행이 항상 앞으로 나아가는지 확인한다.

## 하지 말 것

- 토큰 수 기준으로 바꾸기 (특정 모델에 묶인다)
- 여러 문서의 텍스트를 하나로 합쳐 나누기 (출처를 잃는다)
- 완전한 의미 단위 분할 구현 (MVP 범위 밖)
- 빈 조각을 결과에 넣기
