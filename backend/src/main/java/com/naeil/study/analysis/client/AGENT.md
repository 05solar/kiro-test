# analysis/client — 에이전트 작업 규칙

## 지킬 것

- 도메인은 `AiAnalysisClient` 만 본다. 구현체를 직접 주입하지 않는다.
- SDK 예외를 `AiAnalysisException` 으로 감싼다.
- 구조화 출력을 쓴다. 자연어 응답을 파싱하지 않는다.
- 응답 record 필드는 감싼 타입(`Integer`, `Boolean`)으로 둔다.
- 모델 ID와 API 키는 설정값으로 받는다.
- 타임아웃을 반드시 설정한다. 외부 호출을 무한정 기다리지 않는다.

## 하지 말 것

- 프롬프트 전문이나 AI 응답 전문을 로그로 출력
- 응답 검증을 여기서 수행 (validation 패키지의 몫이다)
- 응답 형식 오류를 여기서 재시도 (상위 서비스가 판단한다)
- API 키가 없을 때 기동 실패시키기
- 테스트에서 실제 API 호출
