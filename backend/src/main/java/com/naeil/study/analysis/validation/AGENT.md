# analysis/validation — 에이전트 작업 규칙

## 지킬 것

- AI 응답을 검증 없이 저장하지 않는다.
- 문서 참조는 요청에 실제로 넣은 값만 허용한다.
- 보정할 때마다 로그를 남긴다.
- 상한값(제목 길이, 학습시간 범위, Topic 수)을 상수나 설정값으로 둔다.
- `TopicImportance.from` 의 관대함을 여기서 중복 구현하지 않는다.

## 하지 말 것

- 값이 조금 벗어났다고 전체 실패시키기 (비용이 크다)
- 출처 참조가 전부 잘못됐다고 Topic 버리기
- 여기서 재시도 (상위 서비스가 판단한다)
- AI 응답 전문을 로그나 예외 메시지에 넣기
