# 루트 패키지 — 에이전트 작업 규칙

## 지킬 것

- 새 클래스는 **도메인 패키지 안**에 만든다. 루트에 파일을 늘리지 않는다.
- `common` 에 넣기 전에 "지금 두 곳 이상에서 쓰는가?"를 확인한다.
- 도메인 간 의존은 한 방향으로만 만든다. 순환 참조가 생기면 설계를 다시 본다.
- 다른 도메인의 Repository를 직접 호출하지 않는다. 서비스를 통한다.

## 하지 말 것

- `StudyBackendApplication` 에 `@Bean` 추가
- 계층 우선 패키지 구조(`controller/`, `service/`)로 되돌리기
- `common` 에 특정 도메인 규칙 넣기 (예: 세션 코드 규칙은 `session/entity` 에 있다)
