# session/controller — 에이전트 작업 규칙

## 지킬 것

- 컨트롤러는 얇게 유지한다. 매핑과 변환만 한다.
- 생성자 주입만 쓴다.
- 생성은 201 Created, 조회는 200 OK 를 명시한다.
- 응답은 항상 DTO로 변환해서 반환한다.

## 하지 말 것

- 코드 생성 로직을 컨트롤러에 넣기
- 엔티티를 그대로 반환
- try-catch 로 예외를 잡아 직접 응답 만들기 (GlobalExceptionHandler 가 처리한다)
- 컨트롤러에 @Transactional 붙이기
- 쿼리 파라미터로 세션 코드 받기 (경로 변수로 통일한다)
- 응답 헤더나 로그에 세션 코드 전체를 남기기 (접근 키다)
