# session/dto — 에이전트 작업 규칙

## 지킬 것

- record 로 만든다.
- 엔티티에서 DTO로의 변환은 DTO의 정적 팩터리 from() 에 둔다.
- 응답 필드 순서는 엔티티 필드 순서를 따른다. 문서와 대조하기 쉬워진다.
- 값이 없으면 null 로 내려보낸다. 키를 생략하지 않는다.

## 하지 말 것

- 엔티티를 컨트롤러에서 그대로 반환
- 내부 id(UUID)를 응답에 포함
- @JsonInclude(NON_NULL) 추가 (키가 사라져 클라이언트 분기가 깨진다)
- DTO 안에 비즈니스 로직 넣기
- 요청 DTO와 응답 DTO를 하나로 합치기
