# studycontext/service — 에이전트 작업 규칙

## 지킬 것

- 생성자 주입만 쓴다.
- 저장은 Upsert 하나로 유지한다. 생성 전용 / 수정 전용 메서드를 나누지 않는다.
- 정규화는 저장 직전에 한 번만 한다. 컨트롤러나 엔티티에서 중복하지 않는다.
- 조회 결과가 없을 때 예외를 던지지 않는다. `Optional` 을 그대로 돌려준다.
- 시각은 주입받은 `Clock` 에서 얻는다.

## 하지 말 것

- 학습 맥락 입력으로 세션 상태 변경
- 학습 맥락이 없다고 404 던지기
- `StudySessionRepository` 직접 사용
- 사용자 입력 내용을 로그에 통째로 출력
