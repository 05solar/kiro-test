# studycontext — 에이전트 작업 규칙

## 지킬 것

- 저장은 항상 Upsert다. 세션당 행이 하나여야 한다.
- 조회 조건은 항상 세션 ID다. 다른 세션의 맥락이 넘어올 경로를 만들지 않는다.
- 세션은 `SessionService` 를 통해 가져온다. `StudySessionRepository` 를 직접 쓰지 않는다.
- 입력값은 `StudyContextPolicy.normalize` 를 거쳐 저장한다. 공백만 있으면 `null` 이다.
- 시각은 주입받은 `Clock` 에서 얻는다.
- 긴 텍스트 컬럼에 `@Lob` 을 붙이지 않는다. PostgreSQL에서 본문 대신 OID가 저장된다.

## 세션 상태를 바꾸지 않는다

학습 맥락 입력 여부로 `StudySession.status` 를 바꾸지 않는다.
세션 상태 머신과 독립적인 선택 정보다.

## 없음은 오류가 아니다

학습 맥락을 입력하지 않은 세션 조회에 404를 쓰지 않는다.
200에 전부 `null` 로 응답한다. 선택 입력이라 "없음"이 정상 상태다.

## AI 연동 시 (STEP 6)

- 학습 맥락을 시스템 프롬프트 문자열에 **직접 이어붙이지 않는다.**
  시스템 지시문과 사용자 제공 맥락을 구조적으로 분리한다.
- 사용자 입력을 검증된 사실로 취급하지 않는다.
- `교수 강조 × 2.0` 같은 숫자 가중치를 하드코딩하지 않는다.
  먼저 프롬프트 컨텍스트로 전달해 품질을 보고, 필요성이 확인된 뒤에 규칙을 넣는다.
- `mustStudyAreas` 는 가중치가 아니라 제약이다. 시간이 부족해도 커리큘럼에서 빼지 않는다.
