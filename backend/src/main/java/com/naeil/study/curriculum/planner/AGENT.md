# curriculum/planner — 에이전트 작업 규칙

## 지킬 것

- 배정 시간의 합이 가용 시간을 넘지 않게 한다. 결과를 돌려주기 전에 확인한다.
- 정책은 `CurriculumPolicy` 에만 둔다.
- 우선순위는 Comparator 로 표현한다. 숫자 점수를 쓰지 않는다.
- 입력과 출력에 JPA 엔티티를 쓰지 않는다.
- 최종 순서는 `topicOrder` 를 따른다.
- 진행이 항상 앞으로 나아가는지 확인한다 (무한 루프 방지).

## 하지 말 것

- Planner 안에서 DB 조회나 AI 호출
- 배정 시간이 권장 시간을 넘게 만들기 (최초 계획에서는 금지)
- `mustStudy` 주제를 중요도로 걸러내기
- 남는 시간을 억지로 모두 소비하기
- 정책 숫자를 절대적 기준처럼 문서화하기 (휴리스틱이다)
