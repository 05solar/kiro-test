# document/service — 에이전트 작업 규칙

## 지킬 것

- 생성자 주입만 쓴다.
- 세션은 SessionService 를 통해 가져온다. StudySessionRepository 를 직접 쓰지 않는다.
- 검증은 DocumentFileValidator 에 맡긴다. 서비스에서 조건을 다시 쓰지 않는다.
- DB 저장은 saveAllAndFlush 를 쓴다. 커밋 시점 실패는 보상 삭제를 할 수 없다.
- 보상 삭제 실패로 원래 예외를 덮지 않는다. 로그만 남기고 원래 예외를 올린다.
- 시각은 주입받은 Clock 에서 얻는다.

## 하지 말 것

- 업로드 중 일부만 저장하고 부분 성공 응답 반환
- 트랜잭션 안에서 오래 걸리는 파일 작업 몰아넣기 (4단계 파싱에서 특히 주의)
- 삭제 순서 뒤집기 (Storage 먼저 지우면 파일 없는 메타데이터가 남을 수 있다)
- 파일 내용이나 바이너리를 로그로 출력
- 세션 코드 전체를 로그에 반복 노출 (로그에는 sessionId 를 쓴다)
