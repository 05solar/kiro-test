# document/parser — 에이전트 작업 규칙

## 지킬 것

- 파서는 텍스트 추출만 한다. 정규화, 상태 변경, DB 접근을 하지 않는다.
- 라이브러리 예외를 그대로 올리지 않는다. `DocumentParseFailedException` 으로 감싼다.
- 실패 사유는 짧은 내부 요약 문자열로 남긴다. 라이브러리 원문 메시지를 넣지 않는다.
- 스트림은 try-with-resources 로 닫는다.
- 파일 경로를 직접 조합하지 않는다. `StorageService` 가 준 스트림만 읽는다.

## 정규화

- 줄바꿈을 지우지 않는다. 문서 구조가 사라진다.
- 줄 안의 연속 공백을 축약하지 않는다. 코드·수식·표 정렬이 무너진다.
- 들여쓰기를 지우지 않는다. 계층 정보다.

## 하지 말 것

- OCR 추가 (MVP 범위 밖)
- 파서에서 AI 호출, 요약, 청킹, 토큰 계산
- 추출한 텍스트 전체를 로그로 출력
- `if/else` 형식 분기를 서비스나 컨트롤러에 만들기 (팩터리를 쓴다)
- 소스에 보이지 않는 문자를 그대로 쓰기 (코드 포인트 상수로 둔다)
