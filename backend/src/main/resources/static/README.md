# static — API 테스트 콘솔

`index.html` 하나뿐이다. 백엔드가 직접 서빙하므로 브라우저에서 `http://localhost:8080/` 로 연다.

## 왜 여기에 두는가

같은 오리진이라 CORS 설정이 필요 없다. 별도 정적 서버로 띄우면 `file://` 이나 다른 포트가 되어
모든 `/api` 호출이 CORS 로 막힌다. 지금 프로젝트에는 CORS 설정이 없다.

## API 키를 이 폴더에 두지 않는다

AI를 호출하는 것은 백엔드다. 프론트는 `/api` 만 부른다.
키를 자바스크립트에 넣으면 페이지를 여는 누구나 개발자 도구로 볼 수 있다.

```bash
AI_PROVIDER=gemini GEMINI_API_KEY=... ./gradlew bootRun
```

## 용도

개발 중 손으로 흐름을 확인하기 위한 것이다. 실제 서비스 화면이 아니다.
세션 코드는 `localStorage` 에 남아 새로고침해도 이어진다.

```
세션 → 시험 정보 → 자료 업로드/추출 → 학습 맥락 → AI 분석
     → 학습 계획 → 단계 시작/완료 → 퀴즈 → 오답 요약
```

5 · 7 · 8 단계는 실제 AI를 호출한다. 과금된다.
