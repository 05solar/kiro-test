# scripts — AI 에이전트 작업 규칙

- **실제 AI 를 부르는 스크립트를 만들지 않는다.** 이 폴더의 스크립트는 반복 실행이 전제다.
  한 번 돌릴 때마다 과금되면 아무도 돌리지 않게 된다. `LLM_MODE=mock` 을 전제로 쓴다.
- **API 키를 스크립트에 적지 않는다.** 환경변수나 `.env` 로만 받는다.
- 세션 코드·UUID 를 스크립트에 하드코딩하지 않는다. 매번 새로 만들어 쓴다.
- 검증에 실패했을 때 **제품 코드를 고치기 전에 스크립트가 틀린 것은 아닌지 먼저 본다.**
  실제로 초기 실패 5건 중 4건이 스크립트 쪽 문제였다(인코딩, 경로, `$?` 덮임).
- 스크립트를 고쳤으면 `docs/general-knowledge-test.md` 같은 결과 문서도 같이 갱신한다.
  둘이 어긋나면 문서가 틀린 것으로 본다.
